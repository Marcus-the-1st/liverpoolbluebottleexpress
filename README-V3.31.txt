V3.31 — PRODUCT IMAGE STANDARDISATION TEST

Purpose:
- Establish the new product-image standard using Don Julio Reposado as the test product.
- The supplied real bottle image is preserved; only the surrounding canvas/background and crop/scale were prepared for consistent website display.
- Standard canvas: 800 x 800.
- Bottle is scaled consistently within the canvas while keeping its original proportions and the complete bottle visible.
- Background is clean white.
- Both Don Julio image filenames were synchronized to prevent an old image reference from reappearing.
- catalog-data.js now explicitly points Don Julio Reposado to special-don-julio-reposado.png.

Going forward:
- New product photos should be prepared to this same visual standard.
- Do not stretch or redraw bottles.
- Keep the complete cap and bottle base visible.
- Remove excess empty space around the bottle before placing it on the standard canvas.
